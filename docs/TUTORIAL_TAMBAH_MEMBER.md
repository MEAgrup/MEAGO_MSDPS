# Tutorial: Menambahkan Member ke MSDPS

Aplikasi: **https://app.meago.id**

> **Batas waktu SPV/Lead: 29 September 2026, 17.00 WIB.**
> Lewat jam itu, penambahan member hanya bisa dilakukan OD/HR.

---

## A. SPV / Lead — menambahkan anggota tim

1. Login ke **https://app.meago.id**.
2. Klik menu **Kelola Karyawan** di sidebar kiri.
3. Scroll ke kartu **Tambah Anggota Tim [divisi Anda]**.
4. Isi 2 kolom:
   - **Nama Lengkap**
   - **Email** (email kantor yang dipakai untuk login)
5. Klik **Tambah Anggota Tim**.
6. Muncul kotak hijau berisi **password sementara** (format `MEAGO-XXXX-XXXX-XXXX`).
   **Salin sekarang** — password ini hanya tampil sekali.
7. Kirim email + password sementara itu ke anggota tim ybs lewat **chat pribadi**, bukan grup.
8. Ulangi langkah 3–7 untuk anggota berikutnya.

**Batasan:** divisi dan level terkunci (Staff, divisi Anda). Untuk menambah Lead/SPV, mengubah,
atau menonaktifkan data karyawan → minta OD/HR.

---

## B. Member baru — login pertama kali

1. Buka **https://app.meago.id**.
2. Masukkan **email** + **password sementara** dari SPV → **Masuk**.
3. Layar **Ganti Password Sementara** muncul otomatis. Isi:
   - **Password Baru** (minimal 8 karakter)
   - **Ulangi Password Baru**
4. Klik **Simpan Password** → langsung masuk ke Dashboard.

Password sementara tidak berlaku lagi setelah langkah ini. Selanjutnya login pakai password sendiri.

**Password sementara hilang/lupa sebelum sempat login?** Minta OD/HR reset (bagian C-3).

---

## C. OD / HR & Director

### C-1. Menambah karyawan (semua divisi & level)
1. **Kelola Karyawan** → kartu **Tambah Karyawan**.
2. Isi Nama, Email, Divisi, Level. Centang **OD** / **Director** bila perlu.
3. **Password Awal**: kosongkan → sistem membuatkan password sementara.
   Biarkan centang **Password ini sementara** agar pemiliknya wajib ganti saat login pertama.
4. Klik **Tambah Karyawan** → salin password yang muncul, serahkan ke ybs.

### C-2. Mengatur / menutup akses SPV
1. **Kelola Karyawan** → kartu **Jendela Onboarding SPV/Lead**.
2. Ubah **Tutup otomatis pada (WIB)** untuk memperpanjang/mempercepat → **Simpan Pengaturan Jendela**.
3. Untuk mencabut langsung: klik **Cabut akses SPV/Lead sekarang**.

### C-3. Reset password karyawan
1. **Kelola Karyawan** → cari nama di tabel.
2. Klik **Reset password** di kolom Aksi.
3. Salin password sementara yang muncul, serahkan ke ybs.

---

## D. Cek status

Di tabel **Daftar Karyawan**:

| Kolom | Arti |
|---|---|
| **Password: sementara** | belum ganti password sendiri — ingatkan untuk login |
| **Password: sendiri** | sudah aman |
| **Ditambahkan oleh** | nama yang menambahkan akun tersebut |

---

## E. Kalau gagal

| Pesan / kejadian | Lakukan |
|---|---|
| "Email sudah terpakai oleh akun lain" | Email itu sudah punya akun — cek tabel Daftar Karyawan |
| "Jendela onboarding ditutup" / kartu Tambah Anggota Tim tidak muncul | Lewat batas waktu → minta OD/HR |
| Menu **Kelola Karyawan** tidak ada di sidebar | Akun Anda bukan SPV/Lead, atau jendela sudah tutup |
| Password sementara terlanjur tertutup/hilang | Minta OD/HR reset (C-3) |
